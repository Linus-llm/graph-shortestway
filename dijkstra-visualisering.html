Pile viser vejens retning. Tallene på vejene er kilometer mellem byerne; tallene ved noderne er bedste kendte samlede afstand fra start. Placeringen er skematisk.

Sådan bruges optagelsen

1. Kør main i Dijkstra.java. Konsollen viser placeringen af dijkstra-trace.json.
2. Vælg JSON-filen øverst på denne side.
3. Brug Næste trin eller Afspil. Forrige og Nulstil afspiller den samme optagelse igen.

Java optager de faktiske dist, prev, visited og køposter ved hvert valg. Den grønne rute rekonstrueres i Java via metodens prev. For at ændre start, mål eller vejnet ændrer du Java-koden og kører den igen. Indlæs derefter den nye fil.

Visited bliver mørkegrå præcis ved visited.add i din metode. Målet bliver grønt ved break og behøver ikke være i visited. Køen vises ved at polle en kopi af Javas PriorityQueue; den oprindelige kø ændres ikke. Dubletter bevares, og allerede besøgte køposter vises overstreget. Ved ens afstande følger rækkefølgen den konkrete Java-optagelse. Optageren medtager grafen, der kan nås fra start og mål.
